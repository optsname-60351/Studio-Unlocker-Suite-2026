## FAQ

### Which video editors does VideoPatch currently support?

VideoPatch supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. Support for additional editors may be added in future updates.

### Is it safe to run videopatch.exe on my computer?

VideoPatch is distributed as a clean executable with no bundled software. Always download from the official repository to ensure file integrity.

### What is the password to extract the ZIP archive?

The extraction password is videopatch (lowercase). Use 7-Zip, WinRAR, or the built-in Windows extractor to unzip the file.

### What should I do if the patcher fails to activate a feature?

Make sure you are running videopatch.exe as administrator, that the target editor is closed, and that your version of the editor is compatible.

### Does VideoPatch require an active internet connection to work?

No, VideoPatch operates entirely offline. No data is sent to external servers during the activation process.

### Will these activations survive software updates from the editor developer?

Major updates from the editor may overwrite patched files. Re-run VideoPatch after any significant software update to restore premium features.

### Can I use VideoPatch on macOS or Linux systems?

VideoPatch is designed exclusively for Windows desktop systems. There is currently no macOS or Linux version available.

### How do I revert the changes if I want to restore the original editor?

Most supported editors offer a repair or reinstall option through Windows Programs and Features. Reinstalling the editor will restore original files.

### Is there a limit on how many times I can use VideoPatch?

No, VideoPatch has no usage limits. You can activate as many supported editors as you need on your Windows machine.

### Which version of Windows is required to run VideoPatch?

VideoPatch supports Windows 10 and Windows 11 (both 32-bit and 64-bit). Older versions of Windows are not officially supported.
